# Birthday Surprise for Mumma
Static site, no installs. Open `index.html` (tap "ENTER IF YOU DARE..." so audio can start).
Deploy: push this folder to a GitHub repo, then Settings > Pages > Deploy from branch `main` / root.
Photos are in `assets/p1.jpg ... p11.jpg`; captions live in the `caps` array in `script.js`. Add a photo by adding a file and a caption.
Fonts load from Google Fonts (free) with fallbacks. Test the sound at low volume first: the jump scare is loud!
Meri Maa (your own mp3): save as assets/meri-maa.mp3 and it plays automatically during the photos.
